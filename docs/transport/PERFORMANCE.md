## 已知风险

- `BuildFreightRibbons` 在视图构建时对每条边采样高度并生成 cubic 控制点，大市场冷批次可能受 CPU 限制；需实测。
- `FreightEngine::Build` 在分配失败时会在每次请求重算（不做逐帧重试，但无效输入重复请求仍有成本）。
- 视图缓存按筛选内容逐项保存，32 项上限可能对大市场内存有影响；需实测每项大小（segments + ribbons）。
